# Git Test — Practice Repository

Repositori ini berisi template landing page statis berbasis **Start Bootstrap New Age**, dengan HTML, CSS, JavaScript, SCSS, dan aset vendor. Nama repo serta teks di beberapa file menunjukkan ini adalah area latihan Git, bukan aplikasi produksi.

## Struktur ringkas

- `index.html` — halaman landing page
- `css/`, `scss/` — stylesheet
- `js/` — skrip halaman
- `img/`, `device-mockups/`, `vendor/` — aset dan dependensi frontend
- `gulpfile.js`, `package.json` — konfigurasi toolchain template lama

## Status saat ini

**Konflik Git di bagian hero `index.html` sudah diselesaikan** dengan satu judul yang valid: “Belajar dan Berkembang Bersama Komunitas Programmer”. Tautan unduhan palsu ke Google Play/App Store dan tautan sosial/footer placeholder juga sudah dihapus; halaman sekarang menyatakan bahwa aplikasi mobile belum tersedia dan memakai tautan GitHub, LinkedIn, serta email yang nyata. Ini membersihkan masalah yang ditemukan, tetapi belum berarti seluruh template lama telah lolos audit produksi.

## Melihat file

Buka `index.html` di browser untuk memeriksa template. Untuk pengembangan lanjutan, gunakan toolchain yang sesuai dengan konfigurasi repositori; `package.json` saat ini tidak mendefinisikan script npm `start`, `dev`, atau `build`.

## Tujuan belajar

Repositori ini paling cocok untuk latihan memahami perubahan file, staging, branch, dan penyelesaian merge conflict. Sebelum dijadikan portofolio aplikasi, lanjutkan pembersihan aset dan toolchain template lama serta dokumentasikan modifikasi yang benar-benar dibuat.
